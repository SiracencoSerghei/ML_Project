📊 Churn Prediction Web Application

Веб-застосунок для прогнозування відтоку клієнтів телекомунікаційної компанії (Customer Churn).

Користувач вводить характеристики клієнта та отримує:

  • ймовірність відтоку
  • бінарний прогноз (піде / залишиться)
  • рівень ризику

Machine Learning частина

Модель побудована з використанням scikit-learn Pipeline, який об'єднує preprocessing та модель в одному об'єкті.

Артефакти ML


churn/ml/
├── model/
│   ├── churn_model.joblib
│   └── model_info.pkl
├── training_data/
│   ├── feature_names.pkl
│   └── internet_service_churn.csv
  • churn_model.joblib — навчена Pipeline модель
  • feature_names.pkl — порядок і список фіч для inference
  • model_info.pkl — метрики та інформація про моделі

⚠️ Великі файли збережені з використанням Git LFS

Вибір моделі

Було протестовано декілька моделей машинного навчання:

  • Logistic Regression
  • Random Forest
  • XGBoost

Для кожної моделі оцінювались метрики: F1-score, ROC-AUC, Precision, Recall.

Найкраща модель обирається автоматично на основі F1-score на validation set.

Фінальна модель

У веб-застосунку використовується Pipeline з найкращою моделлю, яка включає всі кроки обробки даних та прогнозування.
